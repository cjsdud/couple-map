# 백로그 (사용자 메모 기반)

우선순위·범위 미확정 항목. 확정되면 마일스톤에 편입.

## 1. 핀 디자인·지도 배경색 설정 (2026-07-21 메모)

- 요구: 핀 모양/색을 고르고, 지도(도화지) 배경색도 바꾸고 싶다.
- 설계 메모:
  - 커플 공유 설정이므로 `couples`에 `theme jsonb` 컬럼 권장 (`{ pin: 'heart', pinColor: '#...', paper: '#...' }`).
  - 팔레트는 도화지 토큰 계열로 큐레이션 (자유 색상환은 정체성 훼손 위험) — 핀 모양 3~4종(동그라미·하트·별·마스킹테이프), 배경 3~4종(종이 톤).
  - 명세 §3.2 "스트릭 보상 = 테마·프레임 재화"와 자연 결합: 기본 2종 무료 + 스트릭 달성으로 해금하면 리텐션 루프에 편입됨.
  - 구현 범위: 우리 탭 설정 카드 + ConquestMap/SpotOverlay 토큰화 (색 하드코딩 제거).
- 상태: **사용자 확정 대기** (해금형으로 갈지, 전부 무료로 갈지).
