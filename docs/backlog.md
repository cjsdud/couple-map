# 다음에 할 일 (2026-08-02 사용자 메모)

사용자가 직접 적어 준 다음 작업 3건. 순서는 아래 번호 그대로.

## 3. 공유 카드 — 테마 업그레이드 (사용자 커스터마이징)

- 요구: 지금은 고른 스타일대로만 나온다. **사진 위치·크기를 직접 조절**하고 싶다.
- 현재까지 된 것 (v2, 2026-07-31~08-02):
  - 스타일 7종 · 테마 6종 · 비율 3종 · 사진 고르기와 순서 · 사진 크기 슬라이더(70~130%).
- 남은 것: **위치** 조절. 크기는 슬라이더가 있지만 사진을 어디에 놓을지는 아직 고정이다.
- 설계 메모:
  - 자유도를 높이면 "무엇을 골라도 실패하지 않는다"는 v2 원칙(계획 §2)과 부딪힌다.
    끌어다 놓기보다 **정해진 자리 중 고르기**(위/가운데/아래, 왼쪽/오른쪽)가 안전하다.
  - 사진 안에서의 **크롭 위치**(얼굴이 잘리는 문제)는 자유 조절이 실제로 필요할 수 있다 —
    지금은 위쪽 38% 기준 고정. 미리보기에서 사진을 위아래로 미는 정도면 충분해 보인다.
  - 프레임 기울기·마스킹테이프 유무 같은 장식 토글도 후보.
- 상태: **범위 확정 필요** (어디까지 자유롭게 둘지).

## 4. 데이트 등록 — 스팟별·사진별 코멘트

- 요구: 데이트 장소마다, 또는 사진마다 코멘트를 달 수 있게. 전체 코멘트(지금의 메모)는 유지.
- 현재: 기록에 메모 한 칸(`records.memo`)만 있다. 사진은 스팟에 태그만 걸린다
  (`record_photos.spot_id` — plan-multi-region B안).
- 설계 메모:
  - 스팟별 코멘트는 `spots.note` 컬럼 추가로 간단. 사진별은 `record_photos.caption`.
  - 어느 쪽이 주인지 정해야 한다 — 둘 다 열면 입력 화면이 무거워진다.
    "스팟마다 한 줄"이 데이트 기록의 결에 더 맞고, 사진별은 인스타 캡션에 가깝다.
  - 공유 카드와 연결: 스팟별 코멘트가 있으면 티켓·매거진 카드가 훨씬 풍부해진다.
  - 작성 시트(RecordSheet)가 이미 길다 — 스팟 카드를 접었다 펴는 형태로 넣어야 한다.
- 상태: **기획 필요** (사용자 명시).

## 5. 가계부 — 보기 편하게

- 요구: 가계부를 눌러서 들어가거나 다른 경로로, 지금보다 편하게 볼 수 있게.
- 현재: 우리 탭의 월간 카드 하나(합계·횟수·평균·밸런스)뿐. 개별 지출은 기록 상세를 열어야 보인다.
- 설계 메모:
  - 절대 규칙 1(화면 3개)이 있으므로 **새 탭·새 화면은 금지** — 월간 카드를 탭하면 열리는
    바텀시트가 정답에 가깝다.
  - 시트 안에 있으면 좋을 것: 월 이동, 카테고리별 비중, 지출 목록(날짜·장소·금액·낸 사람),
    항목을 누르면 그 기록 상세로.
  - 명세 §3.3·§5.4 톤 규칙 유지 — 정산 압박·경고색·리더보드 금지.
- 상태: 범위는 비교적 명확. 착수 가능.
