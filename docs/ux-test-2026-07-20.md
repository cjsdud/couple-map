## 수정하지 않고 기록만 남기는 관찰

1. 데모 모드 문구에 'Supabase' 어휘 노출 — 키 설정 시 안 보이는 경로라 유지 (실서비스 미노출).
2. 질문 카드의 '답 남기기' 비활성 사유가 데모 모드에서 미표기 — 동일 사유로 보류.
3. 타임라인 카드 탭 → 기록 상세(사진·스팟 미니맵) 바텀시트 없음 — M1 후속 (스키마·경로 준비됨).
4. 지도 확대·팬 없음 — v1은 개요 정복 지도 스펙 그대로 (동네 줌은 핀 상세 미니맵으로, tech-design §3③).
5. 서울 등 수도권 밀집 지역은 축소 지도에서 스팟 점이 몰려 보임 — 서울 서브 정복판(v1.5)에서 해소 예정.
