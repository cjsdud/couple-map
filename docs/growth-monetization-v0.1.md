# 성장·수익화 설계 v0.1 (2026-08-03)

사용자(박천영)와의 설계 세션 결과. "사용자를 많이 모으면서 수익화"의 구조를 정한다.
백로그 §1(핀·배경 해금 여부)의 상위 문서 — 여기서 정한 방향이 §1의 답이 된다.

## 0. 움직일 수 없는 전제

1. **루프 과금벽 금지** (CLAUDE.md 절대 규칙 3) — 핀·오늘 업로드·질문·잔디는 영원히 무료.
   수익은 꾸미기·소장·실물에서만 나온다.
2. **공유 카드는 유료화하지 않는다** — 인스타에 올라가는 카드가 곧 광고다.
   성장 엔진에 요금소를 달지 않는다. 카드는 오히려 계속 좋아져야 한다.
3. **결제 수납은 사업자 등록이 선행** — PG 가입·전자상거래 신고 모두 사업자번호 필요.
   운영자가 은행 재직 중(겸직 제약)이라 앱인토스를 접게 한 그 문제가 그대로 적용된다.
   → 겸직 허가 확인(또는 대안) 전까지 수납은 불가. **경제 설계는 지금, 수납 스위치는 나중.**
4. **다크패턴·비교·리더보드 금지** (명세 §5, §3.3) — 해금을 미끼로 한 재촉 알림 금지,
   커플 간 비교 기능 금지 (초대 보상은 되, 순위는 안 된다).

## 1. 성장 루프 — 해금 조건이 곧 성장 행동

- Acquisition: 인스타 공유 카드(워터마크) · /install 랜딩 · 초대 링크
- Activation: 첫 핀 (첫 실행 안내 기존재)
- Retention: 잔디·스트릭 + **해금 보상** ← 이 설계의 자리
- Referral: ①짝꿍 초대(구조상 필수, K≈1 내장) ②친구 커플 초대 (결정 대기)
- Revenue: 맨 마지막. 커플당 LTV = 구독 + 실물.

원칙: **해금 조건은 전부 위 루프에 기여하는 행동**으로만 고른다.
스트릭(리텐션), 정복 n곳(코어 사용), 카드 공유(유입 기여), 100일/1주년(복귀 트리거).

## 2. 해금 경제 — 추상 재화 없이, 업적 직해금

크레용 포인트류 게임머니는 **넣지 않는다**: 감성 훼손, 밸런싱 노동, 나중에 유료
재화와 충돌. 조건 → 아이템 직결로 간다 ("잔디 7일 → 별 핀").

| 티어 | 여는 법 | 내용물 |
|---|---|---|
| 기본 | 처음부터 | 핀 2종(동그라미·하트) · 종이 2톤 · **공유 카드 스타일·테마 전부** |
| 활동 해금 | 잔디 7일/30일 · 정복 5/15/30곳 · 카드 첫 공유 · 100일 · 1주년 | 핀 4~6종 · 종이 3~4톤 · 카드 스티커 변형 |
| 시즌 한정 | 해당 시즌에 활동 (조건 낮게) | 벚꽃·여름 바다·크리스마스 등 — 희소성·복귀 트리거 |
| 유료 팩 | P1 이후 | 지난 시즌 재판매 + 프리미엄 팩 |

- 잠긴 항목은 **미리보기로 보여준다** + 조건 한 줄 ("잔디 7일을 채우면 열려요").
  욕망은 만들되 재촉 알림은 보내지 않는다.
- **기존 베타 사용자는 grandfather** — BETA_ALL_UNLOCKED 시절에 쓰던 것은 그대로 유지.
  (couples.theme에 열린 목록을 저장해 두는 방식. 초기 지지자에게서 뺏지 않는다.)

## 3. 수익화 3단계

- **P0 (지금)**: 수납 없음. 해금 경제 가동, 관리자 페이지로 리텐션·해금 지표 검증.
  화면에 "유료" 딱지 자체를 노출하지 않는다.
- **P1 (겸직 확인 후)**: **도화지 플러스** — 커플 구독 월 2,900~3,900원, 한 명 결제로
  둘 다 적용. 내용물: 사진 원본 화질 보관·용량 확장, 한정 테마 전부, 연간 리캡 고급판,
  백업/내보내기. + 단건 테마 팩 1,900~3,300원. (국내 커플 앱 구독 시세권)
- **P2 (실물 — 차별화 무기)**: 연말 "우리의 1년" 포토북 + **정복 지도 포스터 인쇄**.
  정복 지도는 경쟁 앱이 복제 못 하는 자산, 커플 선물 지불의사 높음. 주문형 인쇄 제휴로
  무재고. 객단가 15,000~35,000원 — 구독보다 커질 수 있다.
- **광고는 하지 않는다** — 일기 옆 배너는 '둘만의 공간'이라는 핵심 자산을 부순다.

## 4. 결정 (2026-08-03 사용자)

1. **친구 커플 초대 보상** — ✅ 진행. 구현됨: 소개 링크(`/install?ref=<couple_id>`) →
   새 커플 행에 `referred_by` 귀속(0018) → active 1쌍부터 '단짝 핀'(하트 둘 겹침) 해금.
   우리 탭에 소개 카드(보내기·링크 복사·성과 뱃지). 비교·순위 없음.
2. **시즌 한정** — 보류. 나중에 다시 논의.
3. **전환 시점** — 해금 전환은 아직 안 함 (`BETA_ALL_UNLOCKED = true` 유지).
   대신 꾸미기를 먼저 예쁘게: 핀 6종(리본·단짝 추가)·종이 6톤(민트빛·라벤더 추가),
   꾸미기 카드에 실시간 미리보기(작은 도화지 조각) + 핀 칩을 실제 SVG 모양으로.
   사용자가 직접 테스트 후 전환 여부 결정.

## 5. P0 구현 순서 (결정 후 착수)

1. 해금 엔진 — unlockable 정의(핀·종이·시즌) + 조건 평가(클라 계산, 서버 검증은 P1에서)
2. 우리 탭 '도화지 꾸미기' 카드 확장 — 잠긴 항목 미리보기 + 조건 문구
3. 해금 대상물 제작 — 핀 3~4종·종이 2톤 추가, 시즌 1탄
4. BETA_ALL_UNLOCKED 해제 + 기존 유저 grandfather 마이그레이션
5. 관리자 페이지에 해금·리텐션 지표 (스트릭 분포, 해금 도달률)
6. 카드 공유 시트에 /install 링크 텍스트 동봉 (카톡 경유 유입 — 인스타는 무시하므로 무해)
