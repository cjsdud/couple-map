# 우리의 도화지 — 기능 명세서 v0.4

작성일: 2026-07-19 · 상태: 기획 확정
v0.3 → v0.4 변경: 지도 홈 확정, 상호 잠금 상시 설명, 재방문 처리(클러스터·덧칠·단골), 회색 핀 v1 승격, 다스팟 기록 구조, 정복 단위 시군구 확정, 오늘 기록 노출 정책, 퍼센타일 상시 노출 위치·보호 규칙

## 1. 제품 정의

- **이름**: 우리의 도화지 (홈 화면 축약 "도화지"). 도화지 속에 '지도'가 들어있다 — 빈 도화지를 채워간다 = 빈 지도를 색칠해간다. 스토어 부제: "우리의 도화지 — 커플 지도·데이트 기록·가계부". 백업 후보: 그린지도.
- **한 줄 정의**: 우리가 사랑한 모든 장소로 채워가는 한 장의 도화지.
- **핵심 가설**: 커플의 리텐션은 ①매일의 상호 잠금 루프(습관)와 ②쌓여서 이전 불가능해지는 공간 기반 추억 자산(락인)에서 나온다.
- **네트워크 효과**: 발행된 코스 라이브러리가 지역별로 쌓이며 커플 간 네트워크 효과 형성.
- **타깃**: 한국 20대 커플 (앱인토스 정책상 만 19세 이상).
- **포지셔닝**: 카톡은 대화를, 우리는 장소와 날들을 기록한다. 채팅 없음.
- **경쟁 요약**: 비트윈(채팅·하락세), 썸원(질문·텍스트 자산), Widgetable(위젯·아카이브 없음), 커플패스(할인·락인 없음), 유니플(다기능·IA 붕괴). 공간 자산 + 공유 카드 + 코스 네트워크 조합은 공백지대.

## 2. IA 원칙 (불변 규칙)

1. 화면은 **지도(홈) / 오늘 / 우리** 3개. 홈 = 지도 (사용자 검증 완료).
2. 새 기능은 새 화면을 만들 수 없다. 레이어·카드·모달로만 추가.
3. 모든 핵심 행동은 2탭 이내.
4. **투어는 금지, 설명은 맥락 안에서**: 온보딩 기능 투어 없음. 대신 상호 잠금 등 규칙이 있는 UI는 그 자리에서 상시 문구로 설명 (예: 잠금 카드의 "내 사진을 올리면 짝꿍의 오늘이 열려요"). 첫 실행 = "첫 데이트 장소에 핀 찍기" 행동 유도.
5. 루프(핀·오늘 업로드·질문·잔디)는 절대 유료화하지 않는다.
6. **프라이버시 철칙**: 원본 추억은 자동 공개되지 않는다. 공개는 "발행"의 파생물로만.
7. **비교는 홈에 없다**: 타 커플 대비 통계는 '우리' 탭과 공유 카드에서만. 지도 홈은 우리 이야기 전용.

## 3. 화면별 명세

### 3.1 지도 (홈)

| 기능 | 상세 | 버전 |
|---|---|---|
| 데이트 기록(핀) | **1기록 = 스팟 1~5개(같은 날)** + 사진 1~N장 + 한 줄 메모 + 날짜 + 지출(선택). 지도에 스팟별 점 표시, 동일 기록 스팟은 점선 연결. 메모·지출은 기록 단위 | v1 |
| 스팟 입력 방식 | ①장소 검색(지도 SDK 로컬 검색) ②"지금 여기"(GPS). 지도 롱프레스 수동 지정은 v1.5 | v1 |
| 핀 분기 | + 버튼 첫 단계에서 **다녀왔어요 / 가고 싶어요** 분기. 데이터는 status(visited/planned) 필드 하나로 관리 | v1 |
| 회색 핀(가고 싶은 곳) | **v1 승격 (최소 스코프)**: 저장·지도 표시·"다녀왔어요" 전환(→컬러 핀) 만. 코스 저장 연동은 v3 | v1 |
| 정복 색칠 | **단위 = 시·군·구 (전국 229개)**. 상단 "대한민국 O.O% 정복". 동 단위는 과분화(3,500+, 정복률 정체), 시·도는 조기 소진 → 229개가 달성감·수명 균형점. 정복 판정은 **데이트 핀(visited)만** | v1 |
| 서울 서브 정복판 | 서울 확대 시 "서울 25구 정복" 별도 표시 (수도권 집중 커플 대응) | v1.5 |
| **재방문 처리** | ①**클러스터**: 동일 장소 핀은 묶고 "×N" 뱃지, 탭 시 시간순 기록 목록 ②**덧칠**: 방문 횟수에 비례해 크레용 빗금이 진해짐(1회 연함 → 5회+ 꽉 채움) — 도화지 컨셉의 시각 언어 ③**단골 승격**: 5회+ 장소는 단골 핀 | ①② v1 / ③ v1.5 |
| 지역 뱃지 | 시·도 첫 방문 뱃지, 핀 10개 동(洞) = "우리 동네" 자동 지정 | v1.5 |
| 뷰 토글 | 지도 ↔ 타임라인. **타임라인에는 오늘 기록도 통합 표시** (필터: 전체/데이트만/오늘만) | v1 |
| 지출 히트맵 | "돈 제일 많이 쓴 동네" 토글 | v1.5 |
| 코스 탐색 레이어 | 우리 지도 ↔ 모두의 코스 | v3 |
| 공유 | 정복률 카드 | v1.5 |

| 오늘의 질문 | 1일 1질문, 양쪽 답변 시 상호 공개 (상시 설명 문구 동일 원칙) | v1 |
| 기분 이모지 | 1탭 참여 | v1 |

| 스트릭 | 둘 다 채운 날 연속. 보상 = 테마·프레임 재화. 벌칙 없음 | v1 |

## 4. 데이트 가계부 상세

- 입력: 기록 단위 종속. 금액 + 낸 사람 + 카테고리 5개 고정(밥/카페/놀이/이동/선물). 다건. 10초 이내.
- 밸런스 톤: "요즘엔 OO이 자주 냈어요" 수준 (검증 완료). 경고색 금지. 부담 비율 설정 기준 계산.
- 공유 격리: 공유 카드에서 지출 자동 제외.
- 핀 없는 지출: v2. 정산 송금 딥링크: v1 제외 확정, 수요 확인 시 v2 기본 꺼짐 옵션.

## 5. 코스 공유 & 기록 통계 (소셜 설계)

- 원칙: 커뮤니티가 아니라 콘텐츠. 게시판·댓글·팔로우 없음.
- **코스 발행 (v3)**: 다스팟 기록 구조가 원천 데이터 — v1 스키마가 코스를 선행 준비. 발행 포함: 장소·순서·카테고리·지역·새 한줄평·선별 사진. 미포함: 원본 메모·지출·인물 사진·날짜·커플 식별 정보.
- 코스 탐색: 지도 레이어. 좋아요·저장·신고 3개. 저장 → 회색 핀 세트 가져오기 (탐색→계획→기록→발행 플라이휠).
- 퍼센타일: 리더보드 없음. '우리' 탭 상시 카드(§3.3 규칙) + 공유 카드.
- 운영: UGC 신고·차단·약관 필수, 위장 광고 코스 대응(신고 임계 숨김·발행량 제한), 시드 코스 20~30개, 밀도 지역부터 단계 오픈.

## 6. 질문 콘텐츠 운영

- AI 사전 생성 730개 → 사람 검수 후 탑재. 런타임 비용 0.
- D+ 기반 분기(초기/중기/장기), 금지 주제 필터(전 애인·결혼 압박·외모 비교·돈 갈등), 카테고리 태그 요일 배분, 연 1회 추가 배치.

## 7. 바이럴 설계 (공유 카드 5종, 워터마크+링크)

1. 월간 회고 2. 기념일 3. 정복률 4. 월말 잔디 5. 퍼센타일.
구조적 K팩터: 가입 시 상대 초대 강제 + 공유 카드 외부 유입.

## 8. 수익화

토스 인앱결제 미사용 확정.

| 채널 | 역할 | 결제 |
|---|---|---|
| 앱인토스 | 100% 무료 유입·검증 | 없음 |
| App Store / Play Store | 리텐션 본진(위젯) + 구독 | 스토어 IAP (15%) |
| 실물 커머스 | 최고 마진 기둥 | 외부 PG (~3%) |

무료: 압축(장변 1,600px)·핀당 10장·기록/잔디/질문 무제한. 구독(월 4,900/연 39,000, 커플 단위): 원본 화질·핀당 무제한·고급 템플릿·테마/위젯·상세 리포트. 공통: 오늘 30장/일 기술 상한.
실물: 연간 지도 포스터·포토북 (압축본 인쇄 불가 → 원본 가치를 커머스가 증명). 광고 없음. LTV 전제 ~18개월 → 실물·시즌 전환이 실질 기둥, 이별 시 "추억 내보내기" 유료.

## 9. 로드맵

- **v1 (앱인토스)**: 커플 연결 / 다스팟 데이트 기록·시군구 정복·클러스터·덧칠·회색 핀(최소)·타임라인(오늘 통합) / 오늘(자유 업로드·상시 설명 잠금·위치 태그·핀 승격·질문·기분·잔디·스트릭·커플별 마감) / 디데이 / 가계부 월간 카드.
- **v1.5**: 월간 회고+공유 카드, 예산, 히트맵, 지역 뱃지·단골 승격·서울 25구, 롱프레스 스팟 지정.
- **v2 (네이티브)**: OS 위젯, 구독 IAP, 연간 결산, 핀 없는 지출, 퍼센타일 상시 카드+공유, (조건부) 정산 딥링크.
- **v3**: 코스 발행·탐색, 인쇄 커머스, 기념일 제휴. **v3+**: 지역 제휴.

채널 이전: 계정 기반 완전 동기화. 위젯·구독이 네이티브 전환 유인.

## 10. 기술 제약 메모

- 모바일 단독 개발 (웹 + GitHub 배포). 앱인토스 웹 미니앱 우선, 검수 1~3개월.
- 네이티브: Capacitor + GitHub Actions/Codemagic 클라우드 빌드.
- 사진 압축: 업로드 시 클라이언트 처리.
- 행정구역 경계: 공공 시군구 GeoJSON (무료). 정복 판정 = 스팟 좌표 → 시군구 매핑.
- 코스(v3) 신고 백오피스: 관리 웹 1페이지.

## 11. 미결정 사항

1. 이름 최종 컨펌 (추천: 우리의 도화지) — 스토어 제출 시 중복 최종 확인.
2. 코스 발행 사진 공개 정책 상세 (v3 시점).
3. 퍼센타일 최소 표본 수 (v2 시점).
4. 지도 SDK 선정·비용 (네이버/카카오/Mapbox — 기술 설계에서 확정. 앱인토스 호환성·로컬 검색 API 포함 비교).
